Previsão de Risco de AVC (Stroke Prediction)

Este projeto tem como objetivo investigar até que ponto as características demográficas, hábitos de vida e condições médicas de um paciente podem ser utilizados para estimar a probabilidade de sofrer um Acidente Vascular Cerebral (AVC).O projeto fez o uso de um dataset externo , que consiste em uma tabela de dados crus que representam informações básicas de cada paciente , que ao serem processados, podados e analisados pelo programa com o auxílio de um modelo capaz de identificar possíveis tendencias ou relações implícitas entre esses dados , transformam-se em uma saída que simboliza se um determinado indivíduo da tabela será alvo ou não da doença .
